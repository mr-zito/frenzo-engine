YouTube says "confirm you're not a bot"? How to get the file
  1. In Opera GX, add the extension Get cookies.txt LOCALLY (it saves the file on your PC, sends nothing).
  2. Open a private window and sign in to youtube.com, ideally with a spare Google account.
  3. On youtube.com click the extension, Export, then close the private window right away.
  4. Upload that file here. Frenzo uses it for every YouTube download. If YouTube blocks again later, upload a new one.
The file is your YouTube login: it stays in the frenzo-engine folder, never share it.
